# SOLID Calisthenics : EcoTrip Calculator

## Consignes

> Durée : 1h · 1 fichier `REFACTORING.md` par groupe

Vous allez **refactorer le code** de l'**EcoTrip Calculator** en appliquant au minimum :
- **1 principe SOLID**
- **1 pattern du GOF**
- **2 règles Object Calisthenics**

Chaque transformation doit être **documentée** dans un fichier `REFACTORING.md` déposé sur le canal prévu.

> Format du livrable `REFACTORING.md` disponible via [Refactoring Template](REFACTORING-TEMPLATE.md)

---

## Barème — 20 points

### Principe SOLID (6 pts)

| Critère                                                                                 | Points |
|-----------------------------------------------------------------------------------------|--------|
| Le principe est **correctement identifié** et nommé                                     | 1 pt   |
| La violation originale est **localisée et expliquée** dans le contexte du code          | 2 pts  |
| La transformation est **réellement implémentée** dans le code (pas seulement décrite)   | 2 pts  |
| Le bénéfice est formulé en termes **concrets et métier** — pas une définition générique | 1 pt   |

### Pattern GOF (6 pts)

| Critère                                                                                      | Points |
|----------------------------------------------------------------------------------------------|--------|
| Le pattern est **pertinent** par rapport au problème identifié                               | 2 pts  |
| La **structure du pattern** est correctement mise en place (interfaces, classes, délégation) | 2 pts  |
| Le pattern est **réellement implémenté** dans le code                                        | 2 pts  |

### Object Calisthenics (6 pts — 3 pts par règle)

| Critère                                                          | Points |
|------------------------------------------------------------------|--------|
| La règle est **identifiée et localisée** dans le code original   | 1 pt   |
| La transformation est **implémentée** et cohérente avec la règle | 1 pt   |
| Le code résultant **respecte effectivement la règle**            | 1 pt   |

### Recul critique — "Ce qu'on ferait ensuite" (2 pts)

| Critère                                                                                                            | Points |
|--------------------------------------------------------------------------------------------------------------------|--------|
| La prochaine transformation est **identifiée et justifiée**                                                        | 1 pt   |
| L'argumentation montre une **compréhension des liens** entre les trois dimensions (SOLID / pattern / calisthenics) | 1 pt   |

---

## Ce qui sera pénalisé

- Transformation décrite et **non implémentée dans le code**
- Principe / règle / pattern **mal nommé ou confondu**
- Explication **générique** non ancrée dans le code `EcoTrip` → −0.5 pt par occurrence
- Tests en échec ou supprimés → −2 pts
- Fautes d'orthographe 😉 -> -1 pt
