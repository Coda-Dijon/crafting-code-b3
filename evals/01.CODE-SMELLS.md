## Format du rapport `AUDIT.md`

```markdown
# Audit Code Smells — EcoTrip Calculator
**Groupe :** [Prénom 1, Prénom 2, Prénom 3]

## Code Smells identifiés

### 1. [Nom du smell] — `[fichier.ts:ligne]`
- **Explication :** pourquoi c'est un problème dans ce contexte précis
- **Impact :** ce que ça rend difficile (lisibilité, testabilité, évolutivité…)

```typescript
// Extrait du code concerné
function calculate(t: string, d: number, p: number, f: number, s: boolean) {
  if (t === 'plane') { return d * 0.255 * p * (s ? 1.1 : 1) * f }
  else if (t === 'car') { return d * 0.21 * p * f }
  else if (t === 'train') { return d * 0.041 * p * f }
  else if (t === 'bus') { return d * 0.089 * p * f }
  // ...
}

[…répéter pour chaque smell]

## Synthèse
[Quel smell corrigeriez-vous en premier, et pourquoi ? 3-4 phrases max.]
```

## Barème — 20 points

### Identification (8 pts)

| Critère                                                     | Points |
|-------------------------------------------------------------|--------|
| Au moins 5 smells identifiés et **expliqués correctement**  | 4 pts  |
| Smells issus d'au moins **2 catégories différentes**        | 2 pt   |
| Chaque smell est **localisé** (fichier + ligne ou fonction) | 2 pt   |

### Qualité des explications (8 pts)

| Critère                                                                                                             | Points |
|---------------------------------------------------------------------------------------------------------------------|--------|
| L'explication est **contextualisée** — pas une définition générique recopiée                                        | 3 pt   |
| L'**impact** est formulé en termes concrets ("impossible d'ajouter un mode de transport sans toucher à 4 endroits") | 3 pt   |
| Un **extrait de code** illustre au moins 2 smells                                                                   | 2 pt   |

### Synthèse (4 pts)

| Critère                                                    | Points |
|------------------------------------------------------------|--------|
| La priorisation est **justifiée**                          | 2 pt   |
| La synthèse **argumente** — elle ne reliste pas les smells | 2 pt   |

## Ce qui sera pénalisé

- Smell listé sans explication ni localisation → **non compté**
- Définition générique copiée-collée sans lien avec le code → **−0.5 pt**

> Vous pouvez identifier des Code Smells qui vont à l'encontre des idioms du langage.
